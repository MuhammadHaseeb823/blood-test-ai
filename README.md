# blood-test-ai
# 🩸 Blood Test AI Diagnostic System

AI-powered clinical decision support system for hematology screening.

---

## 🚀 Features
- 25+ hematological condition detection
- AI-style clinical explanations
- Severity-based interpretation
- Interactive medical UI (Streamlit)
- PDF report generation
- Educational medical tool

---

## ⚙️ How to Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
